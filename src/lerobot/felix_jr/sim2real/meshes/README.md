# Meshes

- **`xlerobot_finger.stl`**: the XLeRobot's Fin Ray finger, the white ribbed finger on our robot's jaws. From the
  XLeRobot project, https://github.com/Vector-Wangel/XLeRobot (Apache License 2.0,
  https://github.com/Vector-Wangel/XLeRobot/blob/main/LICENSE), copied unmodified on 2026-11-14 (sha256
  `41879e02a13fd73fd2fefdf16b26c99a1b5cce9b420f10832fa8fbad92df7ea8`). In millimeters, in the coordinates of the
  assembly it was exported from; `robot.py` (`FINGER_*`) places it on our jaws. Stored with git LFS (as every `.stl`
  in this repository): run `git lfs pull` after cloning.
